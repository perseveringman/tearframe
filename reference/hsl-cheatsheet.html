🔬 HSL 调色速查卡

核心逻辑：选一种颜色 → 单独改它的色相/饱和度/明度 → 不影响其他颜色。

三个滑块的作用

滑块做什么往正方向往负方向
色相 (H)改变颜色种类色轮顺时针偏移色轮逆时针偏移
饱和度 (S)改变鲜艳程度更鲜艳更灰
明度 (L)改变亮暗更亮更暗

8 色通道对应关系

通道画面中对应常见用途
红嘴唇、红色衣物、红花调口红色、红色物体
橙⭐ 肤色、暖光、木质肤色优化（最高频）
黄阳光、秋叶、黄色物体暖调加强、秋色
绿植物、草地翠绿化（色相+偏青）
青水面反光、阴天天空水色调整
蓝天空、海面、蓝色衣物天空加蓝、海面加深
紫紫色花、霓虹灯特殊场景
洋红粉色物体、部分灯光特殊场景

高频场景速查

🧑 肤色白皙：橙色 → 饱和度 -15~-30 / 明度 +10~+25 / 色相不动或微调
🌊 天空更蓝：蓝色 → 饱和度 +20~+40 / 明度 -10~-20 / 色相微 -5（偏青）
🌿 草地翠绿：绿色 → 色相 +15~+30（偏青）/ 饱和度 +10~+30 / 明度 +5~+15
🌅 日落加强：橙色 → 饱和度 +15~+30 ｜ 黄色 → 色相 -10（偏橙）

安全范围 ⚠️

操作安全范围超出后果
肤色色相±10 以内变绿/变紫 = "生病感"
肤色饱和度-30 以内过低 = 灰/丧尸
肤色明度+25 以内过高 = 塑料/苍白
天空饱和度+40 以内过高 = 荧光蓝
绿色色相+30 以内过高 = 不自然的青

口诀

色轮管"区域"（暗/中/亮），HSL 管"颜色"（红/橙/黄/绿/青/蓝/紫）。两者配合 = 氛围 + 精修。
