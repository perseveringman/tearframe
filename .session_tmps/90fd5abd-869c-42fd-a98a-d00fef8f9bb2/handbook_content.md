# 学习记录视频创作操作手册

## 流程总览

```
PHASE 0  启动准备        第0天，1小时
PHASE 1  调研与计划      第1-7天
PHASE 2  学习与拍摄      第1-30天，每天5分钟
PHASE 3  脚本定稿        第30天完成后，2小时
PHASE 4  素材整理        半天
PHASE 5  剪辑            1天
PHASE 6  审片与输出      2小时
PHASE 7  封面标题发布    1小时
PHASE 8  复盘            30分钟
```

---

## PHASE 2：学习与拍摄

### 2-1 每日拍摄规范

**每次练习前**：手机固定，录练习全程（不要手持，要能空出手练习）

**每次练习后**：10秒自我记录，格式：
> "Day X，[今天做了什么]，[一句真实感受]"

固定机位建议：
- 手机架在正前方，与眼睛等高
- 不需要布光，自然光即可
- 背景保持一致（同一个地点），后期混剪时有连贯感

**遇到以下情况立刻拍**：

| 情况 | 拍什么 | 放哪里 |
|------|--------|--------|
| 搞砸/失败/卡住 | 当下表情+3秒内容 | T5 |
| 今天没状态但还是做了 | 开始练习的画面5秒 | T5 |
| 突然感觉对了 | 立刻重复一次完整录下来 | T6 |
| 遇到好方法/工具 | 屏幕录屏或拍屏幕 | T3 |
| 别人给你反馈 | 录下对话或拍截图 | T5/T6 |

### 2-2 每日日记模板（手机备忘录，每天1分钟）

```
Day ___  [日期]

今天做了：___________________________________________
遇到的问题：___________________________________________
一句真实感受：___________________________________________
明天要改的一件事：___________________________________________
```

> 说明：这份日记剪辑时直接变成旁白来源，不是给别人看的，越真实越好。

### 2-3 转折时刻拍摄指引

转折时刻是整个视频最重要的片段，但无法预测何时出现。

**预感到的情况**：把手机架好再做，完整录下来。

**事后才意识到的情况**：立刻对着镜头说：
> "刚才[发生了什么]，我的感受是[真实感受]"

哪怕背景乱、光线差，不需要重拍。真实感 > 画面质量。

### 3-2 旁白写作原则

- 从每日日记里取原句，不要重新发明
- 每句话不超过20个字
- 不解释，只描述和感受
- 最后一句感想：不要说"学会了坚持"这种，说一个具体的认知改变

## PHASE 4：素材整理

### 4-1 精选素材标准

把RAW素材全部过一遍，符合以下任意一条放入01_精选：

| 标准 | 说明 |
|------|------|
| 表情真实 | 皱眉/惊讶/发呆 > 微笑表演 |
| 有时间跨度感 | Day1、中期、Day30 三段都要有 |
| 有环境声 | 真实声音留着，后期可用 |
| 有明显变化 | 前后对比差距明显的片段 |
| 转折时刻完整 | T6素材尽量保留完整片段 |

### 4-2 素材检查清单

整理完成后，确认精选文件夹里有：

- [ ] T1：至少1条第0天失败素材
- [ ] T2：至少1条动机素材
- [ ] T3：至少2条调研/计划素材
- [ ] T4：覆盖Day1、中期、Day30三个时间段的练习素材
- [ ] T5：至少1条"没状态但还是做"的素材
- [ ] T6：至少1条转折时刻素材
- [ ] T7：第1天和第30天做同一件事的对比素材 + 直视镜头感想

如有缺失，第30天补拍。

## PHASE 5：剪辑

### 5-1 剪辑流程（分三步，不要混着做）

**Step 1：装桶（1小时，只做分类不剪辑）**

建6个序列/时间线，把精选素材对应放进去：

```
序列A → T1素材：选最戏剧的1条
序列B → T2素材：选最真实的1条
序列C → T3素材：选最清晰的2-3条
序列D → T4+T5素材：选有时间跨度的5-8条
序列E → T6素材：选最完整的1条
序列F → T7素材：对比素材 + 感想直视镜头
```

**Step 2：录旁白（30分钟）**

对照脚本，一个模块一个模块录。录制要点：
- 不念稿，把意思记在脑子里再说
- 录错了不要停，继续录，后期剪掉
- 每个模块录3遍，选最自然的一遍

**Step 3：组装剪辑（2-3小时）**

按A→B→C→D→E→F顺序，每个模块完成后再进下一个。

模块D过程混剪节奏参考：
- 每个片段2-4秒
- 节奏先慢后快
- 配合旁白的情绪起伏剪切

### 5-2 音乐选择原则

- 开场：无音乐或轻环境音，让失败更真实
- 过程混剪：轻音乐，不要抢旁白
- 转折时刻：可以短暂升调
- 感想结尾：音乐淡出，留最后一句旁白无背景音

## PHASE 6：审片

### 6-1 审片清单（输出前逐条确认）

**内容层面**
- [ ] 开场30秒：如果我是观众，我会继续看吗？
- [ ] 有没有废话（解释性的、没有信息量的句子）
- [ ] 计划那段：观众截图能用吗？文字清晰可读？
- [ ] 转折那段：我有没有真实地表达当时的感受？
- [ ] 最后一句感想：是真的新认知，还是鸡汤？

**技术层面**
- [ ] 声音统一（旁白和现场收音音量平衡）
- [ ] 没有跳帧
- [ ] 字幕准确（如果有）
- [ ] 片尾有没有引导动作（关注/评论/下一期预告）

---

## PHASE 7：封面与标题

### 7-1 封面模板规范

所有11个视频封面统一格式：

```
左侧：你的真实表情照（失败感/惊喜感二选一）
右侧：大字标题，2行以内
底部：小字技能名称 + Day30
色调：统一使用同一种底色（建议选定后11个都用）
```

### 7-2 标题公式

主标题公式（三选一）：
```
公式A：我用30天[做到了什么]（[之前的状态]）
公式B：[具体成果]，从[起点]开始
公式C：[反直觉的感想结论]
```

各技能标题参考：

| 技能 | 公式A | 公式C |
|------|-------|-------|
| 英语口语 | 我用30天说出完整的英语（从录音删掉开始） | 英语口语不需要词汇量，需要开口次数 |
| 声乐 | 我用30天学会控制自己的声音 | 你以为不擅长，只是没人教你对的方法 |
| 做菜 | 我用30天学会做12道菜 | 做菜学得快，是因为每天都要吃饭 |
| 剪辑 | 我用30天学会把想法剪成视频 | 剪辑难的不是技术，是判断 |
| 拍摄 | 我用30天拍出让人问我用什么相机的照片 | 学拍摄改变的不是手，是看世界的方式 |
| 收纳 | 我用30天让自己回家不再感觉累 | 你真正需要的，比你以为的少很多 |
| 口播 | 我用30天从录41遍到一遍过 | 说不清楚，是因为没想清楚 |
| 分析博主 | 我用30天学会"读"视频 | 好的表达不是天生的，是设计的 |
| 跳舞 | 我用30天让身体知道怎么动 | 学跳舞学的不是动作，是对身体的控制 |
| 设计 | 我用30天从将就变成喜欢 | 学设计先练眼，眼光到了手只是时间 |
| 5公里 | 我用30天从800米到5公里 | 不需要今天很好，只需要今天没放弃 |

### 7-3 发布前检查清单

- [ ] 封面导出尺寸正确
- [ ] 标题复制确认无错字
- [ ] 视频描述写好（3行：讲了什么 + 计划时间线 + 下一期预告）
- [ ] 话题标签准备好
- [ ] 发布时间选好（不要深夜发）

## PHASE 8：复盘

### 8-1 发布后48小时复盘模板

```
【发布复盘】技能：___________  发布日期：___________

数据（48小时）：
- 播放量：___  完播率：___  点赞：___  评论：___

评论里最多人提的问题：
___________________________________________

观众在哪里停止看（如果平台有数据）：
___________________________________________

我觉得最薄弱的部分是：
___________________________________________

下一个视频要改的一件事：
___________________________________________
```

### 8-2 11个视频的迭代节奏

不要等11个都做完再复盘。建议：
- 发完第1个视频，看48小时数据，改一件事
- 带着这个改动做第2个视频
- 每发一个都复盘一次，11个视频做完你已经迭代了11次

## 附录：多技能并行时间表

11个技能错峰启动，避免同时进入剪辑期：

```
第1-2周   启动：英语口语
第3-4周   启动：5公里长跑
第5-6周   启动：做菜
第7-8周   启动：收纳
第9-10周  启动：口播
第11-12周 启动：拍摄
第13-14周 启动：剪辑
第15-16周 启动：声乐
第17-18周 启动：跳舞
第19-20周 启动：设计
第21-22周 启动：分析博主表达
```

每个技能从启动到发布约5-6周（30天学习 + 1-2周制作）。

按此节奏，11个视频全部发布完毕约在第7个月，平均每2-3周发一条，频率稳定且不会崩。

## 核心原则（贴在桌上）

```
1. 第0天立刻拍，不要等准备好
2. 每天5分钟素材，不要积累
3. 真实感 > 画面质量
4. 脚本从日记里取，不要重新想
5. 剪辑是组装，不是创作——素材好，剪辑就快
```
