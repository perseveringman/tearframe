Lesson 01 — 色彩的语言

理解调色的底层逻辑，而不是记参数

这节课不会教你"把饱和度拉到+30"。我们要解决一个更根本的问题：当你面对一段素材，你的大脑应该怎么"想"调色？

学完这节课，你将拥有一个思维框架，让你面对任何素材都能做出有依据的调色决策。

一、色彩的三个维度：HSL

所有的调色操作，本质上都是在操控三个东西：

色相 (Hue) — 是什么颜色？红、橙、黄、绿、青、蓝、紫

饱和度 (Saturation) — 颜色有多鲜艳？从灰到纯色

明度 (Lightness/Value) — 颜色有多亮？从黑到白

你可能已经知道这三个概念。但关键不是定义——是理解它们如何决定画面的情绪：

饱和度递减 → 情绪从"活力"走向"沉静/忧郁"

明度递增 → 情绪从"厚重/紧张"走向"轻盈/明快"

💡 核心洞察

调色不是在"修"画面，而是在用色彩的三个维度讲述情绪。当你降低饱和度，你不是在"让颜色不那么艳"，你是在让画面变得克制、冷静、有距离感——这正是"电影感"的核心要素之一。

二、色轮与色彩关系：为什么电影总是"青橙"？

色相不是孤立存在的。它们在色轮上有关系，这些关系决定了画面的和谐度与冲击力：

三种核心色彩关系

  1. 互补色（色轮上对角 180°）— 产生最强对比，如青 ↔ 橙、红 ↔ 绿
  2. 相似色（色轮上相邻 30°~60°）— 和谐统一，如橙 + 黄 + 红
  3. 三角配色（色轮上 120° 间隔）— 丰富但平衡，如红 + 蓝 + 黄

💡 为什么好莱坞爱"青橙"(Teal & Orange)?

人的肤色天然偏暖（橙黄区间）。当你把背景/阴影推向冷色（青蓝），人物肤色和环境形成互补对比，人物自然"跳"出来。这不是审美偏好——是视觉生理决定的。

所以"电影感"的一个核心公式是：暖肤色 + 冷环境 = 自然的主体分离。

三、调色的思维框架：三步决策

面对任何一段素材，你的大脑应该走这三步：

Step 1：诊断 — 这段素材"病"在哪？

  • 曝光是否正确？（太亮/太暗/灰雾？）
  • 白平衡是否准确？（偏蓝/偏黄/偏绿？）
  • 对比度是否足够？（层次感？还是糊成一片？）

→ 这一步对应一级校色：把画面"修正"到中性状态

Step 2：意图 — 我想让观众感受什么？

  • 温暖亲切？→ 暖色温 + 中等饱和
  • 冷峻疏离？→ 冷色温 + 低饱和 + 高对比
  • 梦幻轻盈？→ 提亮暗部 + 低对比 + 柔和色调
  • 电影质感？→ 压暗整体 + 互补色 + 适度脱饱和

→ 这一步是创意决策：选择你的色彩方案和情绪方向

Step 3：执行 — 用什么工具实现？

  • 整体明暗 → 基础面板 / 曲线
  • 分区上色（暗部冷、高光暖）→ 色轮
  • 单独颜色微调（让天更蓝、草更绿）→ HSL
  • 快速风格化 → LUT（但你要知道它在做什么）

→ 这一步才涉及剪映的具体操作，后续课程详解

⚠️ 常见错误思路

错误：打开调色面板 → 随便拉滑块 → 看哪个好看 → 保存

正确：观察素材 → 判断问题 → 确定情绪目标 → 选择对应工具 → 有目的地调整

区别在于：后者每一步都有理由。这就是"懂调色"和"碰运气"的根本差距。

四、"清透感"和"雾蒙蒙"的本质

你提到想让画面"清透，不雾蒙蒙"。我们来拆解这个感觉背后的色彩原理：

❌ 雾蒙蒙：黑不够黑，白不够白，挤在中间

✅ 清透：黑有黑，白有白，层次分明

💡 "清透"的三个要素

  1. 足够的动态范围 — 最暗处要接近黑，最亮处要接近白（但不要"死黑""过曝"）
  2. 适度的对比度 — 明暗之间有清晰的过渡层次
  3. 色彩纯净 — 颜色不混浊，不互相污染。蓝是蓝，绿是绿，不是灰蒙蒙一片

在剪映中的操作翻译：压暗阴影（但不死黑）+ 微提高光 + 适度加对比 + 饱和度不要过低。具体参数下节课讲。

五、小测验

🧠 Quiz 1：色彩关系

电影《银翼杀手2049》中，大量使用了橙色和蓝色的画面对比。这利用的是哪种色彩关系？

A. 相似色 — 色轮上相邻的颜色
B. 互补色 — 色轮上对角的颜色
C. 三角配色 — 色轮上等距三个颜色
✅ 正确！橙和蓝在色轮上相隔约180°，是经典互补色。互补色产生最强的视觉对比和张力——这也是为什么这部电影的画面冲击力如此强烈。
❌ 再想想。橙和蓝在色轮上的位置关系是什么？它们是相邻还是对面？

🧠 Quiz 2：调色思维

你拍了一段室内咖啡店的 Vlog，画面偏黄偏暗。你想要"清透温暖"的感觉。正确的思路顺序是？

A. 先加一个暖色 LUT → 再拉高亮度 → 加饱和度
B. 先校正白平衡（减黄）→ 提亮+加对比 → 再微调色温回暖一点
C. 直接拉高饱和度和对比度，让颜色更鲜艳
✅ 正确！先诊断（偏黄=白平衡问题，偏暗=曝光不足）→ 修正到中性 → 再有意图地加回"温暖"。这样你加的暖是你"选择"的暖，不是原片的"偏色"——两者天差地别。
❌ 提示：调色第一步永远是"诊断"。在原片已经偏色的基础上叠加风格化，结果是不可控的。先校正，再创作。

🧠 Quiz 3：清透感

画面看起来"雾蒙蒙"，根本原因是什么？

A. 饱和度太低了
B. 色温不对
C. 明暗范围被压缩，缺乏动态范围
✅ 正确！"雾蒙蒙"的本质是画面的最亮和最暗差距太小（集中在中间灰区域）。就像大雾天你看不到纯黑和纯白——一切都被"压"在中间了。解决方法是拉开动态范围：让暗部更暗、亮部更亮。
❌ 虽然饱和度和色温也会影响观感，但"雾蒙蒙"最核心的原因是明度层面的——是亮暗范围被压缩了。想想真正的大雾天，你看到的一切都是灰色的中间调。

六、本课总结

  1. 色彩有三个维度（色相/饱和度/明度），调色就是在这三个轴上做有目的的偏移
  2. 色彩有关系（互补/相似/三角），电影感常用互补色制造对比（青橙）
  3. 调色有思路：诊断 → 意图 → 执行，每一步都要有理由
  4. "清透"= 动态范围充足 + 对比适度 + 色彩纯净
