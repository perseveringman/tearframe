Lesson 02 — 一级校色

从"灰片"到"清透"：所有好看色调的起点

上节课我们学了调色思维框架的第一步：诊断。这节课，我们把诊断变成动手——在剪映专业版里，用具体工具把一段"灰蒙蒙"的素材变成"清透的中性画面"。

🎯 本课核心原则

一级校色的目标不是"好看"，而是"正确"。

你要做的是把画面修正到一个中性、准确的状态——曝光正确、白平衡准确、对比度合理。这是一块干净的画布。所有风格化调色（电影感、日系、胶片）都是在这块画布上创作的。

如果你跳过一级校色直接风格化，就像在脏画布上画油画——颜色永远不对。

一、打开你的"眼睛"：示波器

人眼会骗人——你的显示器亮度、环境光线、甚至你的疲劳程度都会影响判断。所以专业调色第一件事是打开示波器，让数据辅助你的眼睛。

🖥️ 剪映中开启示波器

播放器窗口右上角 → 点击"三条杠"菜单图标 → 选择"调色示波器" → 开启

开启后，视频画面下方会出现波形图。

如何看波形图（Waveform）

💡 读波形的关键直觉

  • 顶部 = 画面最亮处，底部 = 画面最暗处
  • 波形挤在中间 = 灰雾、缺乏动态范围 = "雾蒙蒙"
  • 波形从底部延伸到顶部 = 动态范围充足 = "清透"的基础
  • 波形顶到顶/底 = 过曝/死黑 = 细节不可恢复

你的目标：让波形接近但不触及顶部和底部边界。

二、一级校色工作流（5步）

以下是在剪映专业版中进行一级校色的标准顺序。顺序很重要——后面的步骤依赖前面的结果。

1
曝光/亮度 — 让整体明暗回到正常水平
观察示波器：波形中心是否大致在中线位置？
↓
2
白平衡（色温+色调） — 消除色偏，让白色真正是白色
看画面中"应该是白/灰"的区域：墙面、纸张、云朵
↓
3
对比度（高光+阴影） — 拉开明暗层次
分别控制亮部和暗部，而不是只拉"对比度"滑块
↓
4
曲线微调 — 精确控制 S 曲线，强化层次
曲线是对比度的精细版，给你更多控制
↓
5
饱和度 — 最后微调色彩浓郁度
一级校色阶段通常只做小幅调整（±10~20）

三、逐步详解

Step 1：曝光/亮度

操作位置：选中视频片段 → 右侧"调节"面板 → 基础 → 亮度

判断方法：

  • 看示波器：波形整体偏下 → 欠曝 → 往右拉亮度
  • 波形整体偏上 → 过曝 → 往左压亮度
  • 目标：波形中心大致在中线（512 附近）

⚠️ "亮度"vs"光感"

剪映有一个独创的光感参数。它比"亮度"更柔和——同时微调亮度+对比度+高光压缩，过渡更自然。

建议：如果画面只是整体偏暗，优先试"光感"而不是猛拉"亮度"。亮度拉太多容易把暗部噪点暴露出来。

Step 2：白平衡

操作位置：基础面板 → 色温 / 色调

参数控制什么怎么判断
色温蓝 ↔ 黄画面偏蓝（冷）→ 往右加色温；偏黄 → 往左
色调绿 ↔ 洋红(品红)画面偏绿 → 往右加洋红；偏粉 → 往左

💡 "校正"白平衡 ≠ "创意"色温

这一步你做的是消除原片的色偏——让本该是白色/灰色的东西回归中性。

比如室内钨丝灯拍的视频会偏黄，你需要减色温把黄去掉。

之后在风格化阶段，你可能会故意加回一点暖色温——但那是你的"创意选择"，不是原片的"偏色"。两者的区别是：你有控制权。

判断技巧：找画面中"应该是白色或灰色"的物体（白墙、白纸、灰色水泥地），调到它看起来没有明显色偏为止。

Step 3：对比度 — 高光与阴影分离

操作位置：基础面板 → 对比度 / 高光 / 阴影

很多人只拉"对比度"滑块。但这个滑块是粗暴的——它同时把亮的变更亮、暗的变更暗，容易过曝+死黑。

更精细的做法：

  • 高光 往左压 → 抑制过亮区域（恢复天空/灯光细节）
  • 阴影 往右提 → 提亮暗部（恢复暗处细节）
  • 对比度 微加 +10~+20 → 最后整体增强一点层次

❌ 压缩的灰色范围：暗不够暗，亮不够亮

✅ 拉开后：从近黑到近白，层次分明

Step 4：曲线 — 对比度的精细版

曲线是调色中最强大的工具。它让你精确控制"哪个亮度区间变亮/变暗多少"。

操作位置：调节面板 → 曲线 → 选择"亮度"通道（白色线）

💡 S 曲线的本质

S 曲线做的事情只有一件：拉开中间调的明暗差距。

  • 暗部锚点往下拉 → 中等暗的像素变得更暗
  • 亮部锚点往上提 → 中等亮的像素变得更亮
  • 两端（纯黑纯白附近）不动 → 避免过曝/死黑

这就是为什么 S 曲线能让画面"清透"——它拉开了层次，而且比对比度滑块更温柔，因为你可以控制"从哪里开始拉"。

⚠️ S 曲线的度

轻微的 S = 自然清透。过度的 S = 画面硬、噪点放大、过渡断层。

经验法则：每个锚点的位移不超过曲线图高度的 10-15%。如果你需要更大的调整，说明前面的亮度/对比度步骤没做到位。

Step 5：饱和度微调

操作位置：基础面板 → 饱和度

一级校色阶段，饱和度的调整应该是克制的：

  • 原片看起来灰扁 → 加 +10~+20 恢复正常色彩
  • 原片颜色过艳（某些手机的"鲜艳模式"） → 减 -10~-15
  • 目标：颜色看起来"自然"，既不灰也不艳

大幅度的饱和度调整留给风格化阶段。

四、曲线的 RGB 通道：纠正色偏的精确武器

除了亮度曲线，你还有红、绿、蓝三条单独的曲线。它们能做什么？

通道往上拉 = 加什么往下压 = 加什么用途
红色曲线加红加青纠正偏青/偏红
绿色曲线加绿加洋红(品红)纠正偏绿/偏品红
蓝色曲线加蓝加黄纠正偏蓝/偏黄

💡 为什么比色温滑块更强？

色温滑块是"全局"的——整个画面统一偏蓝或偏黄。但现实中，色偏可能只存在于暗部（比如阴影偏蓝而高光正常）。

用蓝色曲线，你可以只把暗部的蓝压下去（拉暗部区域往下），而高光不变。这是色温滑块做不到的。

现阶段了解即可，实操中先用色温/色调做粗调，如果调不到位再用 RGB 曲线精修。

五、完整操作速查

步骤看什么调什么目标
1. 曝光示波器整体位置亮度 / 光感波形中心在中线
2. 白平衡白色物体的颜色色温 + 色调白色=中性白
3. 对比度波形上下延展范围高光↓ 阴影↑ 对比度微↑波形接近顶底但不触及
4. 曲线中间调层次感亮度曲线做轻微 S层次丰富、过渡自然
5. 饱和度色彩浓度是否自然饱和度 ±10~20颜色看起来正常

六、理解"锐化"的角色

很多教程把锐化放在调色流程里。澄清一下它的本质：

锐化不改变颜色——它增强边缘的明暗对比，让物体轮廓更清晰。它改善的是"清晰度"而非"清透感"。

  • 建议值：30~50（过高会出现白边伪影和噪点放大）
  • 时机：一级校色做完之后加，不是第一步
  • 它不能拯救拍模糊的素材——那是物理限制

七、小测验

🧠 Quiz 1：工作流顺序

一级校色时，为什么要先调白平衡，再调对比度？

A. 没有特别原因，只是习惯
B. 因为色偏会影响你对亮度的判断，先消除色偏才能准确调对比度
C. 因为白平衡要在最干净的画面上调才准确
✅ 正确！色偏（比如整体偏黄）会让你误判画面亮度——黄色看起来更亮，蓝色看起来更暗。先还原真实颜色，你对明暗的判断才是准确的。这就是为什么顺序很重要。
❌ 想想：如果画面严重偏黄，你会觉得它比实际更亮还是更暗？色偏会扭曲你对亮度的感知。

🧠 Quiz 2：S 曲线

S 曲线的暗部锚点往下拉、亮部锚点往上提，本质上在做什么？

A. 让整个画面变亮
B. 增加画面的饱和度
C. 扩大中间调的明暗差距，增强层次感
✅ 正确！S 曲线不改变最亮和最暗（两端不动），而是把"中间灰"区域的像素推向两极——原本接近中灰的暗像素变更暗，原本接近中灰的亮像素变更亮。结果就是中间调层次更丰富——这就是"清透感"的精髓。
❌ 注意 S 曲线的特点：两端（纯黑纯白）不动，只有中间在变化。它不会改变整体亮度，也不直接影响饱和度。

🧠 Quiz 3：实战判断

你的示波器显示波形集中在下半部分（0~400 区域），上半部分几乎是空的。这说明什么？你应该怎么做？

A. 画面欠曝，应该先提亮度/光感，把波形整体往上推
B. 画面对比度不够，应该加对比度
C. 画面过曝，应该压暗高光
✅ 正确！波形集中在下半部分 = 整个画面的亮度信息偏暗 = 欠曝。第一步是提亮整体（亮度或光感），让波形回到合理位置。之后再看是否需要调对比度。
❌ 波形在下半部分意味着画面大部分像素都很暗。"上半部分是空的"说明画面里几乎没有亮的区域——这是典型的欠曝特征。

八、动手练习

🎬 实操任务

打开剪映专业版，找一段你之前拍的"看起来灰蒙蒙"的日常素材，按照以下步骤操作：

  • 开启示波器，观察波形的分布位置
  • 调整亮度/光感，让波形中心回到中线附近
  • 调整色温+色调，让画面中的白色物体看起来是中性白
  • 压高光（-20~-40），提阴影（+20~+40），然后对比度 +10~+15
  • 打开曲线，做一个轻微的 S 曲线（两个锚点，小幅位移）
  • 对比调整前后：是不是从"灰片"变成了"清透"？

📌 关键：不要追求"好看"。一级校色的目标是"正确"——画面看起来自然、中性、层次分明。"好看"是下一步（风格化）的事。
