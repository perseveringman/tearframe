Lesson 03 — 色轮与分区调色

给画面的暗部、中间调、高光分别"染"上颜色——电影感的核心武器

上节课你学会了把灰片变清透（一级校色）。现在画面是一块干净的画布。

这节课开始往画布上"涂颜色"——但不是整块涂，而是分区域涂：暗的地方一种色调，亮的地方另一种色调。这就是电影感调色最核心的技巧。

一、为什么要"分区"上色？

💡 核心直觉

你看到的世界本身就是分区上色的——

  • 阴影里通常偏冷（因为没有直射暖光，只有散射的蓝天光）
  • 高光处通常偏暖（因为太阳光、灯光本身是暖色的）

电影调色师做的事情，就是强化这种自然的冷暖分离，让画面有"空气感"和"立体感"。

如果你只用色温滑块——整个画面统一偏暖或偏冷——画面会"平"。分区上色才能制造层次。

二、色轮工具：三个独立的"调色盘"

🖥️ 剪映中找到色轮

选中片段 → 右侧"调节"面板 → 切换到"色轮"选项卡

你会看到三个圆形色轮：阴影 (Shadows)、中间调 (Midtones)、高光 (Highlights)

🌑

阴影 Shadows

控制画面中暗的区域的色彩倾向

影响力：暗部最强 → 中间调渐弱 → 高光无

🌓

中间调 Midtones

控制画面中中等亮度区域的色彩

影响力：两端弱 → 中间最强

🌕

高光 Highlights

控制画面中亮的区域的色彩倾向

影响力：暗部无 → 中间调渐强 → 高光最强

⚠️ 关键认知：区域是重叠的！

很多人以为三个色轮各管三分之一的画面——其实不是。它们的影响范围是渐变重叠的：

  • 阴影色轮：暗部 100% 影响 → 逐渐减弱 → 高光处 0% 影响
  • 高光色轮：亮部 100% 影响 → 逐渐减弱 → 暗部处 0% 影响
  • 中间调色轮：中间最强，两端减弱（但覆盖范围最广！）

所以中间调是"画面的整体基调"——调它影响面积最大。新手容易忽略它。

三、操作方法

如何使用色轮

  1. 色轮中心有一个小圆点（控制点）
  2. 拖动方向 = 选择你要添加的颜色（往蓝色方向拖 = 加蓝）
  3. 拖动距离 = 控制颜色强度（离中心越远 = 颜色越浓）
  4. 每个色轮旁边通常有一个亮度滑块——控制该区域的整体明暗

💡 核心操作原则：动作要小！拖离中心一点点就够了。色轮非常敏感，拖太远画面会严重偏色。

四、电影感经典配方：暗部冷 + 高光暖

这是最经典、最万能的电影感分区调色方案。理解了它，你就理解了 90% 的电影调色逻辑。

✅ 暗冷 + 亮暖 阴影偏青蓝，高光偏暖橙
= 有空气感、有立体感
❌ 全画面统一暖 只用色温加暖
= 平坦、缺乏层次

💡 为什么"暗冷亮暖"如此有效？三重原因

  1. 符合自然光学 — 现实中阴影接收天空散射光（偏蓝），高光受直射光照（偏暖）。符合人眼预期 = 画面自然。
  2. 肤色分离 — 人的肤色天然在橙黄区间（色轮 15°~35°）。高光偏暖 = 肤色自然；阴影偏冷 = 环境退后，人物凸出。
  3. 色彩对比 — 青和橙是互补色（Lesson 01 学过），互补 = 最强视觉张力。画面自动有"电影感"。

五、三种经典分区配方

🎬 配方 A：经典电影感（青橙 Teal & Orange）

阴影 偏青/蓝绿方向，小幅
中间调 微偏暖（或不动）
高光 偏橙/暖黄方向，小幅

效果：好莱坞大片感、人物突出、空间感强。适合城市、旅行、人像。

🌅 配方 B：暖调怀旧（Golden Hour 延长）

阴影 偏紫/蓝紫方向，小幅
中间调 偏暖橙
高光 偏黄/金色方向

效果：黄金时刻延长感、温暖回忆、夏日午后。适合日落、情侣、治愈类 Vlog。

🧊 配方 C：冷调高级感（Cool Cinematic）

阴影 偏深蓝方向
中间调 微偏冷（或不动）
高光 偏青白/冷白方向，小幅

效果：冷峻、克制、高级。适合都市夜景、科技感、孤独/沉思情绪。

⚠️ 配方不是公式——是起点

这些配方告诉你"方向在哪"，但具体拖多远要靠你的眼睛和素材决定。

同一个配方，室内素材和户外素材需要的强度完全不同。关键是理解为什么这个方向有效——有了理解，你可以随时根据画面反馈调整。

六、常见错误与避坑

错误表现原因怎么修
色轮拖太远画面严重偏色、不自然色轮极其敏感从中心开始，一点一点拖，边调边看
三个区域方向冲突画面"脏"、颜色混浊色彩搭配不和谐坚持互补/相似色逻辑，不要随意
忽略中间调调了阴影高光但画面还是"平"中间调占画面最大面积中间调决定"基调"，不能空着
没做一级校色就上色轮色偏+风格化叠加，颜色不可控画布不干净永远先一级校色，再风格化
肤色变绿/变紫人物看起来"生病"中间调/高光方向影响了肤色避免中间调偏绿；后续用 HSL 保护肤色

七、进阶理解：Lift / Gamma / Gain

如果你未来看到 DaVinci Resolve 或其他调色教程提到 Lift / Gamma / Gain，它们和剪映的"阴影/中间调/高光"色轮本质相同：

专业术语剪映对应影响区域
Lift阴影色轮暗部最强 → 亮部衰减至 0
Gamma中间调色轮中间调最强 → 两端衰减
Gain高光色轮亮部最强 → 暗部衰减至 0
Offset（剪映无直接对应）整个画面统一偏移（≈色温）

知道这个对应关系，你就能看懂任何软件的调色教程，把思路迁移到剪映。

八、小测验

🧠 Quiz 1：分区逻辑

为什么"暗部加青 + 高光加橙"能让人物从背景中自然分离？

A. 因为青色和橙色都很鲜艳
B. 因为人肤色天然偏橙，与青色背景形成互补对比，视觉上自动"跳"出来
C. 因为所有电影都这么调，观众已经习惯了
✅ 正确！人的肤色在色轮上天然处于橙黄区间（约 15°~35°）。当你把环境/暗部推向其互补色（青，约 180°~200°），两者形成最强视觉对比——不需要任何抠图，人物就自然"跳"出来了。这是视觉生理，不是审美习惯。
❌ 提示：想想 Lesson 01 学的互补色原理，再想想人的肤色在色轮上是什么颜色区间。

🧠 Quiz 2：操作判断

你用色轮给阴影加了很多青色，但发现整个画面（包括亮部）都变蓝了。最可能的原因是？

A. 你的素材本身就很蓝
B. 阴影色轮坏了，影响了全局
C. 你的素材整体偏暗，大部分像素都在"阴影"影响范围内
✅ 正确！如果你的素材曝光不足（大部分像素偏暗），那"阴影色轮"实际上影响的面积就非常大——因为几乎全画面都属于"暗部"。解决方法：先做好一级校色（提亮），让画面亮度分布合理，再来用色轮分区。这也再次证明了为什么一级校色必须先于风格化。
❌ 想想：色轮的三个区域是按"亮度"划分的。如果整个画面的像素都很暗，那"阴影"色轮影响的范围会有多大？

🧠 Quiz 3：中间调的角色

三个色轮中，哪个影响画面面积最大、决定画面的"整体基调"？

A. 阴影 — 因为暗部信息量最大
B. 中间调 — 因为大多数像素亮度处于中间区域，且覆盖范围最广
C. 高光 — 因为亮部最引人注目
✅ 正确！在正常曝光的画面中，大部分像素的亮度集中在中间区域。加上中间调色轮的影响范围是三个中最广的（向两端渐变），所以它实际上决定了画面的"整体色调倾向"。新手容易只调阴影和高光而忽略中间调——这是一个常见的遗漏。
❌ 想想正常曝光的画面：像素亮度是正态分布的——中间最多，极暗和极亮较少。再看看中间调色轮的影响范围有多广。

九、动手练习

🎬 实操任务：给你的清透素材上色

拿上节课一级校色好的那段素材（或者任何已经做好一级校色的片段），尝试配方 A（经典青橙）：

  • 切换到"色轮"面板
  • 阴影色轮：把中心点往青色方向（大约 10~11 点钟方向）轻拖一小步
  • 高光色轮：把中心点往橙色方向（大约 4~5 点钟方向）轻拖一小步
  • 中间调：先不动，观察效果
  • 如果画面整体偏冷/偏暖，用中间调微调来平衡
  • 对比开/关效果：是不是画面有了"空气感"？人物是不是更突出了？

📌 最重要的事：动作要小！每次只拖一点点（离中心 1~2mm 的距离）。如果感觉"太假"了，往回收。宁可太淡也不要太浓——高级感 = 克制。

💡 判断"做过了"的标志

  • 白色物体明显偏蓝或偏橙 → 太过了
  • 肤色变绿/变紫/不健康 → 中间调或高光方向有问题
  • 画面看起来像"加了劣质滤镜" → 整体拖太远，全部往回收 50%

好的分区调色应该让人感觉画面"更舒服了"但说不出具体改了什么——这就对了。
