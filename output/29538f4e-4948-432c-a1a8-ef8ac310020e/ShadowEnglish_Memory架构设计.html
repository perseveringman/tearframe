ShadowEnglish Memory 架构设计

项目：/Users/ryanbzhou/Documents/ai-english（Electron + TS 英语听说练习应用）
目标：把「日志式 memory」升级为真正能了解学习者水平的认知型记忆系统

现在的 memory 是一堆「带向量的练习流水」——它能检索「我以前在哪句话栽过」，但回答不了「我现在到底什么水平、哪个知识点掌握了、下一步该练什么」。要让它真正懂你，得在「事件层」之上叠一个会持续蒸馏、随时间衰减、按知识点建模的「画像层」，并把界面里那一堆写死的假数据换成从这一层算出来的真实状态。

一、现状解剖：现有 memory 到底是什么

纵向 · Diachronic

现在有什么

文件职责
ai/memory-agent.ts跟读/复习结果 → MemoryDraft → 写库 + 触发向量化
database.tsmemory_items + memory_embeddings（sqlite-vec，1024 维 Doubao Vision）
shared/types.tsMemoryItem / 5 种 MemoryItemType

记忆类型只有 5 种：weak_area、pronunciation_error、scene_preference、review_performance、cefr_profile。写入只有两个触发点（跟读完拆 3 条、复习完写 1 条），检索是「有 key 走向量、否则降级 LIKE」。

它的真实问题（逐条对照「了解学习水平」）

问题 1 · 只有事件没有画像。 每行都是一次练习的快照，靠 dedupeKey 并列堆叠，没有任何东西把它们聚合成「这个人当前的掌握度」。记忆越攒越多，但「我现在水平如何」没有一条记录能直接回答。
问题 2 · getProgress() 几乎全是写死的假数据（最致命）。 cefrLevel:'B1+'、streakDays:23、masteredCards:Math.max(348,…)、fluencyTrend 曲线、fallbackErrors 假音素表……界面上「你的学习水平」展示的全是 demo 假数据，跟真实练习几乎不挂钩。
问题 3 · 没有知识点（skill）维度。 弱项是自由文本 detail.label，按「材料+句子 index」组织。无法回答「/θ/ 我练了 8 次现在掌握度多少」——因为 /θ/ 不是一等公民。
问题 4 · 记忆不会衰减。 strength 写入即静止。上个月练好的音今天仍被认为「很强」，没有遗忘机制。
问题 5 · 单事件拆条，没有蒸馏。 一句跟读直接炸 3 条，练 100 句就是 300 条原始流水，噪声大、矛盾无人仲裁。
问题 6 · 检索结果没人用。 searchLongTermMemory 有了，但出题/推荐代码里没有任何地方调用它。存了不用，闭环没闭上。
一句话：它是「练习日志 + 向量索引」，不是「学习者模型」。它记得发生过什么，但不理解你现在是谁。

二、业界三套可借鉴范式

横向 · Synchronic

① 认知记忆四象限

类型映射到 ShadowEnglish现状
情节 Episodic「6/3 练第4句，/θ/→/s/，得分71」✅ 现有 memory_items
语义 Semantic「/θ/ 掌握度 0.4」「B1 级，连读弱」❌ 完全缺失（本次核心）
程序 Procedural「出题优先 /θ/+升降调，锁 B1」❌ 散在 hardcode
工作 Working当前 session 临时上下文用完即弃

现状只实现了 Episodic。要懂水平，必须补 Semantic（画像层），并从 Episodic 蒸馏出来。

② Mem0 流水线：提取 → 存储 → 检索 → 更新

  • 提取去噪：事件不直接入库，先提炼「事实/偏好/关系」，滤掉无效信息。
  • 混合检索：语义向量 + BM25 关键词 + 实体匹配并行打分，而非只靠余弦。
  • 更新而非堆叠：新事实与旧记忆比对、合并、解决矛盾，保持精简（entity linking）。

③ 知识追踪 BKT / FSRS

  • BKT：每个知识点维护掌握概率 p(L)，每次答题贝叶斯更新。轻量、可解释、单机能跑、冷启动友好。
  • FSRS：本项目已装 ts-fsrs，cards 表已有 fsrs 字段——记忆稳定度随时间衰减的现成轮子。
启发：用 BKT 思路给每个 skill 维护掌握概率（现在水平），用 FSRS 思路让画像随时间衰减（会遗忘）。两个轮子项目里都已有一半。

四、数据结构设计

新增 skill_catalog（让知识点成为一等公民 · 地基）

CREATE TABLE skill_catalog (
  id        TEXT PRIMARY KEY,   -- 'phoneme:θ' / 'prosody:question-intonation'
  category  TEXT NOT NULL,      -- pronunciation|prosody|fluency|grammar|vocab
  label     TEXT NOT NULL,      -- '齿擦音 /θ/'
  cefr_band TEXT,
  aliases   TEXT DEFAULT '[]',  -- 实体链接: ['/θ/','th音','齿擦音']
  created_at INTEGER NOT NULL
);

冷启动预置 30–50 个常见 skill 种子，第一次用就能归类。

新增 skill_mastery（Semantic 层核心）

CREATE TABLE skill_mastery (
  skill_id       TEXT PRIMARY KEY,
  mastery        REAL DEFAULT 0.3,  -- BKT 掌握概率 p(L)
  confidence     REAL DEFAULT 0.2,  -- 证据越多越可信
  stability_days REAL DEFAULT 1.0,  -- FSRS 稳定度，越高衰减越慢
  exposures      INTEGER DEFAULT 0,
  correct        INTEGER DEFAULT 0,
  trend          REAL DEFAULT 0,    -- 最近趋势 +升 -降
  last_practiced INTEGER,
  updated_at     INTEGER NOT NULL
);

新增 learner_profile（全局画像 · 单行表）

CREATE TABLE learner_profile (
  user_id         TEXT PRIMARY KEY DEFAULT 'local',
  estimated_cefr  TEXT,   -- 由 skill_mastery 反推，不再写死 'B1+'
  cefr_confidence REAL,
  avg_accuracy    REAL, avg_fluency REAL, avg_prosody REAL,
  streak_days     INTEGER,  total_minutes INTEGER,
  strongest_skills TEXT, weakest_skills TEXT,  -- JSON
  updated_at      INTEGER NOT NULL
);

现有 memory_items 不删不改，职责收窄为 L1 情节层：只存原始证据 + 语义检索，聚合型记忆搬到 L2。

五、核心算法（轻量·单机·可解释）

BKT 掌握度更新

function bayesUpdate(prior, correct, pS=0.1, pG=0.2, pT=0.15){
  const pObs = correct ? prior*(1-pS)+(1-prior)*pG
                       : prior*pS+(1-prior)*(1-pG);
  const post = correct ? prior*(1-pS)/pObs : prior*pS/pObs;
  return post + (1-post)*pT;          // 练后有概率"学会"
}
选 BKT 不选 DKT：本地 Electron、无训练数据、要可解释、要冷启动——BKT 全中；DKT 需大量数据训 RNN，单机不划算。

时间衰减（让记忆会遗忘）

function decayMastery(m, stabilityDays, daysSince, floor=0.2){
  const r = Math.exp(-daysSince / Math.max(stabilityDays,0.5)); // 艾宾浩斯/FSRS
  return floor + (m-floor)*r;
}
// 练对→抬高 stability(更牢、衰减更慢)；练错→压低。ts-fsrs 可直接复用

CEFR 反推：不再写死 'B1+'，用各 skill 掌握度按 band 加权聚合落到最近等级，证据少时 confidence 低、界面诚实标「估计中」。

七、为什么这套真正实用

能力怎么实现的
回答得了「我什么水平」learner_profile + skill_mastery 直接、可解释、动态变化
界面不再骗人getProgress 从假数据切真画像
闭环闭上记忆被出题/推荐/复习实际消费
会遗忘会回升衰减 + 复练回升，贴合真实记忆规律
单机轻量BKT + ts-fsrs(已有) + SQLite，全本地无需训练
渐进可落地L1 全保留，加 3 表 + 1 文件，改 3 处调用，不推倒重来

八、落地路线

阶段动作产出
P0建 skill_catalog + 种子；写 resolveSkillId 实体链接弱项能被归类
P1建 skill_mastery + learner-model.ts；接 consolidate画像开始积累
P2改造 getProgress 用真实数据面板不再写死（体感最强）
P3card-generator / recommender 读 L2 + L1 检索闭环闭上，对症下药
P4接 ts-fsrs 精化 stability；CEFR 反推调参衰减与等级更准
建议从 P2 反推优先级：「界面展示假数据」是最直接痛点，把 getProgress 接真，哪怕画像粗糙，体感提升最大。
