PHASE 2 学习与拍摄 第1-30天 · 每天5分钟
核心原则：每天只做一件事——练完立刻拍10秒，扔进对应文件夹。 不要积累，不要"等凑够了再整理"。
17种素材类型速查
类型 拍什么 何时拍
T1 开场失败 第1次做这件事，越真实越好 第0天，立刻拍
T2 动机 若有所思的表情、触发你开始的那一刻 第0天
T3 调研计划 屏幕录屏、笔记、计划页面 第1周
T4 日常练习 每次练习过程，10-30秒，不求好看 每次练习时
T5 状态记录 搞砸的时刻 + 没状态但还是做了的画面 随时
T6 转折时刻 第一次感觉对了的完整片段 感觉突然对了时
T7 成果对比 第1天vs第30天做同一件事 + 感想直视镜头 第30天集中拍
2拍摄规范

固定机位：手机架在正前方，与眼睛等高，不需要布光，自然光即可。背景保持同一地点，混剪时有连贯感。

遇到以下情况，立刻拍：

情况拍什么放哪里
搞砸 / 失败 / 卡住当下表情 + 3秒内容T5
今天没状态但还是做了开始练习的画面，哪怕5秒T5
突然感觉对了立刻重复一次完整录下来T6
遇到好方法 / 工具屏幕录屏或拍屏幕T3
别人给你反馈录下对话或拍截图T5 / T6

4转折时刻拍摄指引
转折时刻是整个视频最重要的片段，但无法预测何时出现。一旦出现，立刻行动。
A
事先预感到

把手机架好再做，完整录下来。不要手持，要能空出手做这件事。

B
事后才意识到

立刻对着镜头说："刚才[发生了什么]，我的感受是[真实感受]"。哪怕背景乱、光线差——真实感 > 画面质量。

5第30天收尾素材清单 T7素材

第30天专门留2小时拍这些，其余时间不用拍。

  • 和第1天相同的事，做一遍，录下来（对比用）
  • 拍所有能展示成果的东西（作品 / 记录截图 / 数据）
  • 安静的地方，手机固定，直视镜头，说感想——不念稿，录多遍取最自然的一遍
  • 把第1天素材和今天素材放一起，自己先看一遍，确认对比够不够明显

2旁白写作原则
原则说明
从日记取原句不要重新发明，真实的话比"写好"的话有力量
每句不超过20字超过就拆成两句
不解释，只描述"我录了41遍" 好过 "这件事说明口播很难"
最后一句要具体"说不清楚是因为没想清楚" 好过 "学会了坚持"
PHASE 4 素材整理 半天
1精选素材标准

把 00_RAW 全部过一遍，符合以下任意一条放入 01_精选。

标准说明
表情真实皱眉 / 惊讶 / 发呆 > 微笑表演
有时间跨度Day1、中期、Day30 三段都要覆盖到
有环境声真实声音留着，后期可用做氛围
有明显变化前后对比差距明显的片段优先选
转折完整T6素材尽量保留完整片段，不要只选最后一帧
2素材完整性检查清单

整理完成后，确认精选文件夹里有：

  • T1 至少1条第0天失败素材
  • T2 至少1条动机素材
  • T3 至少2条调研/计划素材（含可读的计划页面）
  • T4 覆盖 Day1、中期、Day30 三个时间段的练习素材
  • T5 至少1条"没状态但还是做了"的素材
  • T6 至少1条转折时刻素材（完整片段）
  • T7 第1天 vs 第30天对比素材 + 直视镜头感想
如有缺失，第30天补拍，不要跳过。
PHASE 5 剪辑 1天 · 分三步执行，不要混着做
1Step 1：装桶（1小时，只分类不剪辑）

建6个序列/时间线，把精选素材对应放进去：

序列A → T1素材：选最戏剧的1条 序列B → T2素材：选最真实的1条 序列C → T3素材：选最清晰的2-3条 序列D → T4+T5素材：选有时间跨度的5-8条 序列E → T6素材：选最完整的1条 序列F → T7素材：对比素材 + 感想直视镜头
2Step 2：录旁白（30分钟）
1
对照脚本，一个模块一个模块录

不要一口气录完，每个模块之间停一下。

2
不念稿，把意思记在脑子里再说

念稿听起来是念稿，说出来才是说话。

3
录错了不要停，继续录

后期剪掉，比重录一遍省时间。每个模块录3遍，选最自然的。

3Step 3：组装剪辑（2-3小时）

按 A→B→C→D→E→F 顺序，每个模块完成后再进下一个。

模块剪辑要点
A 开场节奏要快，不超过20秒，第一句话是钩子
B 动机画面节奏放慢，让观众代入你的状态
C 计划确保计划页面清晰可读，停留够长（1.5秒以上）
D 过程每个片段2-4秒，节奏先慢后快，配合旁白情绪剪切
E 转折完整保留，不要剪太碎，给观众时间感受
F 感想最后一句旁白无背景音乐，让话落地

音乐节奏：开场无音乐或轻环境音 → 过程轻音乐 → 转折短暂升调 → 感想结尾音乐淡出

PHASE 6 审片与输出 2小时
1审片清单（输出前逐条确认）

内容层面

  • 开场30秒：如果我是观众，我会继续看吗？
  • 有没有废话（解释性的、没有信息量的句子）
  • 计划那段：观众截图能用吗？文字清晰可读？
  • 转折那段：我有没有真实表达当时的感受？
  • 最后一句感想：是真的新认知，还是鸡汤？

技术层面

  • 声音统一（旁白和现场收音音量平衡）
  • 没有跳帧
  • 字幕准确（如果有）
  • 片尾有引导动作（关注 / 评论 / 下一期预告）
PHASE 7 封面标题发布 1小时
1封面模板规范

11个视频封面统一格式，只换内容，不换风格。

左侧：你的真实表情照（失败感 / 惊喜感 二选一） 右侧：大字标题，2行以内 底部：小字技能名称 + Day30 色调：选定一种底色，11个视频全部使用
2标题公式
公式A：我用30天[做到了什么]（[之前的状态]）
公式B：[具体成果]，从[起点]开始
公式C：[反直觉的感想结论]
技能公式A公式C
英语口语我用30天说出完整的英语（从录音删掉开始）英语口语不需要词汇量，需要开口次数
声乐我用30天学会控制自己的声音你以为不擅长，只是没人教你对的方法
做菜我用30天学会做12道菜做菜学得快，是因为每天都要吃饭
剪辑我用30天学会把想法剪成视频剪辑难的不是技术，是判断
拍摄我用30天拍出让人问我用什么相机的照片学拍摄改变的不是手，是看世界的方式
收纳我用30天让自己回家不再感觉累你真正需要的，比你以为的少很多
口播我用30天从录41遍到一遍过说不清楚，是因为没想清楚
分析博主我用30天学会"读"视频好的表达不是天生的，是设计的
跳舞我用30天让身体知道怎么动学跳舞学的不是动作，是对身体的控制
设计我用30天从将就变成喜欢学设计先练眼，眼光到了手只是时间
5公里我用30天从800米到5公里不需要今天很好，只需要今天没放弃
3发布前检查清单
  • 封面导出尺寸正确
  • 标题确认无错字
  • 视频描述写好（讲了什么 + 计划时间线 + 下一期预告）
  • 话题标签准备好
  • 发布时间选好（不要深夜发）
